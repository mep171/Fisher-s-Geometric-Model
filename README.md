# Fisher-s-Geometric-Model
Repository containing all code needed to create landscapes and all plots in the paper "A Framework for Creating Fitness Landscapes Using Fisher’s
Geometric Model" (add link). The model takes fitness measurements of arbritary size and uses Fisher's Geometric model to create a smooth single peak landscape based on the fitness data. Data for the figures in the paper can be found here:Link, alternative data can be artifically generated using the code in the Data folder.
